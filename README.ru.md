# Figma Designer MCP (Talk to Figma MCP + набор Designer Toolkit)

[English](README.md) · **Русский** · Паспорт для агентов: [English](AGENT_PASSPORT.md) · [Русский](AGENT_PASSPORT.ru.md)

**ИИ-агент (Claude Code, Cursor, OpenClaw и любой клиент MCP) проектирует в Figma: вайрфреймы, экраны интерфейса, дизайн-системы и кликабельные прототипы с анимациями.** Работает с **бесплатным аккаунтом Figma** и десктопным приложением.

Это форк проекта [grab/cursor-talk-to-figma-mcp](https://github.com/grab/cursor-talk-to-figma-mcp) (лицензия MIT). Оригинал читает макеты и создаёт простые рамки, прямоугольники и текст. Форк добавляет **Designer Toolkit**: типизированные команды для всего, что делает веб-дизайнер, без выполнения произвольного кода.

Ключевые слова: MCP, Model Context Protocol, плагин Figma, ИИ-агент, Claude Code, Cursor, автоматизация дизайна, вайрфрейм, прототип, auto layout, дизайн-токены, переменные Figma, Smart Animate, веб-дизайн.

## Designer Toolkit (добавлено в этом форке)

| Область | Команды |
|---|---|
| Фигуры и графика | `create_shape` (прямоугольник, эллипс, линия, многоугольник, звезда, с поворотом), `create_placeholder` (плейсхолдер картинки для вайрфрейма: рамка с перекрещёнными диагоналями, подпись и размер в пикселях), `create_from_svg` (иконки, логотипы, произвольные векторы) |
| Внешний вид | `set_appearance` (заливки, обводки, сплошные и линейные/радиальные/угловые/ромбовидные градиенты, скругления, прозрачность, режимы наложения, маски, прокрутка, поворот, размер), `set_effects` (внешние и внутренние тени, размытие слоя, размытие фона для эффекта стекла), `set_layout_grids` |
| Текст | `set_text_style` (шрифт и начертание, размер, межстрочный интервал, трекинг, выравнивание, регистр, подчёркивание, цвет, перенос по фиксированной ширине) |
| Раскладка | `set_auto_layout` (направление, перенос, отступы, поля, выравнивание, режимы размера, абсолютное позиционирование, min/max), `set_constraints` |
| Структура | `arrange_nodes` (группировка, разгруппировка, булевы операции, flatten, маска, порядок слоёв, перенос в другого родителя) |
| Компоненты | `create_component`, `create_variants` |
| Дизайн-система | `create_style` (заливка, текст, эффект, сетка), `apply_style`, `create_variables` (токены: цвет, число, строка, логическое значение, с режимами, например Light и Dark), `bind_variable` |
| Прототипы и анимации | `set_reactions` (триггеры: клик, наведение, нажатие, таймер; действия: переход, оверлей, подмена, смена варианта; переходы Smart Animate, dissolve, push, move, slide; длительность и кривая), `set_flow_start` |
| Служебные | `manage_pages`, `list_fonts`, `find_nodes` |

Цвета принимаются как `"#rrggbb"`, `"#rrggbbaa"` или `{r,g,b,a}` (0–1). Каждая команда типизирована и применяет только документированные свойства Figma Plugin API.

### Безопасность

WebSocket-мост слушает `localhost:3055` **без аутентификации**: любая локальная программа может отправлять команды в открытый файл Figma. Не открывайте порт наружу. В этом форке **намеренно нет** команды «выполнить JavaScript»: она превратила бы локальный порт без пароля в канал запуска кода. Если чего-то не хватает, добавьте типизированную команду.

### Статус

Проверено на живом файле Figma (бесплатный тариф, десктопное приложение): фигуры, повёрнутые линии, градиенты с тенями, импорт SVG, текст с переносом, auto layout, плейсхолдеры, список шрифтов, поиск слоёв, страницы, прототипная реакция Smart Animate. Написано, но ещё не проверено в реальной работе: переменные и стили, варианты компонентов, булевы операции, маски, сетки колонок. Замечания и pull request приветствуются.

### Использование с ИИ-агентами

Смотрите [AGENT_PASSPORT.ru.md](AGENT_PASSPORT.ru.md): установка, порядок работы, приёмы, таблица ошибок и процедура автономного запуска для агентов, которые умеют управлять рабочим столом. Тест, который проверяет набор команд: [scripts/smoke-test.js](scripts/smoke-test.js).

**Важно: запускайте правильный плагин.** В Figma могут быть два похожих плагина:

| | Правильный (из этого репозитория) | Неправильный (сборка из сообщества) |
|---|---|---|
| Где | **Plugins > Development > Cursor MCP Plugin** | основной список Plugins, Saved plugins или Community: «Talk To Figma MCP Plugin» |
| Заголовок окна | **Cursor MCP Plugin** | Talk To Figma MCP Plugin (с иконкой TTF) |
| Крупный заголовок внутри окна | Cursor MCP Plugin, подпись «Designer Toolkit build» | Talk To Figma MCP Plugin |
| Команды Designer Toolkit | работают | отвечают `Unknown command` |

Импорт делается один раз: Plugins > Development > Import plugin from manifest > `src/cursor_mcp_plugin/manifest.json`. Не используйте «Run last plugin», если последним запускался не этот плагин. Не полагайтесь только на название: проверьте заголовок окна и успешный вызов `create_shape` (или `manage_pages` с `LIST`). Затем направьте MCP-клиент на локальный `src/talk_to_figma_mcp/server.ts`:

```json
{
  "mcpServers": {
    "TalkToFigma": {
      "command": "bun",
      "args": ["run", "/абсолютный/путь/к/figma-designer-mcp/src/talk_to_figma_mcp/server.ts"]
    }
  }
}
```

Быстрый старт:

```bash
bun install
bun run src/socket.ts     # мост, держите запущенным
# в Figma: откройте файл, запустите Plugins > Development > Cursor MCP Plugin
# в клиенте агента: join_channel с кодом из зелёной плашки плагина
```

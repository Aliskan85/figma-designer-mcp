# Паспорт для агентов: Figma Designer MCP

[English](AGENT_PASSPORT.md) · **Русский**

Для ИИ-агентов (Claude Code, Cursor, OpenClaw, ZCode, AutoClaw и любых других MCP-клиентов), которые должны проектировать в Figma через этот сервер.

## 1. Что это

MCP-сервер, через который агент создаёт и меняет объекты в открытом файле Figma.
Цепочка: **агент → MCP-сервер (stdio) → WebSocket-мост на localhost:3055 → плагин Figma в десктопном приложении**.
Достаточно бесплатного аккаунта Figma.

## 2. Что должно быть запущено

| Компонент | Как проверить | Как запустить |
|---|---|---|
| Мост | порт 3055 слушается | в корне репозитория: `bun run src/socket.ts` (держать запущенным) |
| Плагин в Figma | окно плагина открыто, зелёная плашка «Connected to server in channel: XXXXXXXX» | открыть файл, затем **Plugins > Development > Cursor MCP Plugin** (раздел 3) |
| MCP-сервер в клиенте | в списке есть инструменты `join_channel`, `create_frame`, `create_shape` | раздел 4 |

Мост останавливается, когда завершается сеанс, который его запустил. Окно плагина держи открытым всё время работы (его можно сдвинуть, но не закрывай). После изменения кода плагина закрой окно и запусти плагин заново.

## 3. Как правильно запустить плагин

Меню плагинов есть только **внутри открытого файла**. Используй **локальный** плагин из этого репозитория:

1. Разовый импорт: **Plugins > Development > Import plugin from manifest...**, выбери `src/cursor_mcp_plugin/manifest.json`.
2. Запуск: главное меню (логотип Figma слева вверху) > **Plugins > Development > Cursor MCP Plugin**.

**Существуют два похожих плагина, правильный только один.** Не доверяй одному названию: знакомое имя здесь типичная ловушка.

| | ПРАВИЛЬНЫЙ (этот репозиторий) | НЕПРАВИЛЬНЫЙ (сборка из сообщества) |
|---|---|---|
| Путь в меню | **Plugins > Development > Cursor MCP Plugin** | основной список Plugins, Saved plugins или Community: **«Talk To Figma MCP Plugin»** |
| Заголовок окна | **Cursor MCP Plugin** | Talk To Figma MCP Plugin (иконка TTF) |
| Заголовок внутри окна | Cursor MCP Plugin, «Designer Toolkit build» | Talk To Figma MCP Plugin |
| Команды Designer Toolkit | работают | отвечают `Unknown command` |

Никогда не выбирай «Talk To Figma MCP Plugin» из основного списка. Не используй «Run last plugin», если последним запускался не локальный плагин. Если запустил не тот, закрой его окно и запусти правильный.

**Доказательство, что запущен правильный плагин** (делай каждый раз): заголовок окна «Cursor MCP Plugin» **и** успешный вызов инструмента набора, например `manage_pages` с `{"action":"LIST"}` или тестовый `create_shape`. `Unknown command` означает, что запущен неверный плагин или старая копия.

**Проверено с агентами:** агенты из AutoClaw 1.17.8 успешно протестировали этот плагин и могут с ним работать (по сообщению владельца). Подтверждённая сборка: десктопное Figma для Windows, бесплатный тариф, локальный плагин, мост и локальный MCP-сервер, как описано здесь.

## 4. Подключение MCP-сервера

Stdio-сервер, локальная копия этого репозитория (опубликованный npm-пакет не содержит Designer Toolkit):

```json
{
  "mcpServers": {
    "TalkToFigma": {
      "command": "bun",
      "args": ["run", "/абсолютный/путь/к/figma-designer-mcp/src/talk_to_figma_mcp/server.ts"]
    }
  }
}
```

После правки конфига перезапусти клиент. OpenClaw: добавь сервер в `mcp.servers` или командой `openclaw mcp set`, затем `openclaw mcp doctor <имя> --probe`. Для других клиентов подойдёт любая конфигурация stdio-MCP с той же командой.

## 5. Порядок работы (обязательно)

1. Возьми **код канала** из зелёной плашки плагина. Он меняется при каждом новом подключении плагина.
2. Вызови `join_channel` с этим кодом.
3. Проверь связь: `get_document_info`. `Request to Figma timed out` значит, что плагин отключён или держит устаревшее соединение: нажми Disconnect, Connect, прочитай новый код и снова выполни `join_channel`.
4. Создай корневой фрейм (`create_frame`), запомни его ID и создавай всё остальное внутри него через `parentId`.
5. После крупных шагов проверяй результат: `export_node_as_image` (scale 0.3–0.5).

## 6. Правила и приёмы

- `x`, `y` дочерних объектов считаются относительно родителя. Созданные позже слои лежат выше.
- Цвета: `"#rrggbb"`, `"#rrggbbaa"` или `{r,g,b,a}` (0–1). Старые инструменты (`create_frame`, `create_text`, `set_fill_color`) принимают только `{r,g,b}` в диапазоне 0–1.
- Текст: `create_text`, затем `set_text_style`. Передай `width`, чтобы получить блок фиксированной ширины с переносом вместо ручных переносов строк.
- Кнопки и подписи по центру: рамка + `set_auto_layout` (`layoutMode`, `primaryAxisAlignItems: CENTER`, `counterAxisAlignItems: CENTER`), текст добавляется с этой рамкой как `parentId`.
- Линии: `create_shape` с `type: LINE`. `width` это длина, `rotation` в градусах против часовой стрелки вокруг левого верхнего угла. Линия вниз-вправо имеет отрицательный угол; диагональ блока w × h имеет длину sqrt(w²+h²) и угол −atan(h/w).
- Плейсхолдеры картинок для вайрфреймов: `create_placeholder` (рамка, две диагонали, подпись и размер в пикселях) одним вызовом.
- Градиенты: `fills: [{type:"GRADIENT_LINEAR", angle:180, stops:[{position:0,color:"#fff"},{position:1,color:"#000"}]}]`. `angle` по правилам CSS (0 вверх, 90 вправо, 180 вниз).
- Эффект стекла: `set_effects` с `BACKGROUND_BLUR` и полупрозрачной заливкой.
- Дизайн-система: токены `create_variables` (режимы, например Light/Dark), `bind_variable`, стили `create_style` и `apply_style`.
- Интерактив и анимация: `set_reactions` (триггер, переход SMART_ANIMATE/DISSOLVE/MOVE_IN/PUSH..., длительность в секундах, кривая), `set_flow_start`. Состояния наведения: компоненты и варианты (`create_component`, `create_variants`) плюс реакция `ON_HOVER` с `CHANGE_TO`.
- Шрифт по умолчанию Inter. Перед другим семейством вызови `list_fonts`.

## 7. Ошибки

| Симптом | Причина | Что делать |
|---|---|---|
| `Must join a channel before sending commands` | не вызван `join_channel` | раздел 5 |
| `Request to Figma timed out` | плагин отключён или устарел | Disconnect, Connect, новый код канала |
| `Not connected to Figma` | не запущен мост | раздел 2 |
| `Unknown command: ...` | неверный или устаревший плагин | запусти локальный плагин заново (раздел 3) |
| `Font not available` | нет такого семейства или начертания | `list_fonts` |
| Инструмента нет в списке | клиент не перезапущен после смены конфига | перезапусти клиент |

## 8. Автономный запуск (пользователя нет рядом)

Сценарий: пользователь в дороге, даёт агенту материалы клиента и просит сделать макет. Агент сам поднимает всю цепочку и сам читает код канала; ждать, пока пользователь пришлёт код, нельзя.

Требование: агент умеет выполнять команды оболочки и управлять рабочим столом (скриншоты, клики, ввод). Без управления рабочим столом плагин не запустить: остановись, опиши, чего не хватило, и дождись пользователя. Не ищи обходных путей и не добавляй выполнение кода.

1. **Мост.** Проверь порт 3055; если закрыт, запусти `bun run src/socket.ts` в фоне и убедись, что выведено «WebSocket server running on port 3055».
2. **Figma.** Если не запущена, запусти десктопное приложение и дождись главного экрана (скриншот). Обычно пользователь уже вошёл; если запрошен вход, остановись и сообщи.
3. **Файл.** Открой последний файл из Recents или создай новый: **Create > Design file**.
4. **Плагин.** Логотип Figma (первый пункт левого меню) > **Plugins > Development > Cursor MCP Plugin**. Никогда не выбирай «Talk To Figma MCP Plugin» из основного списка, Saved plugins или Community (неверная сборка). Если пункта нет, сначала импортируй `src/cursor_mcp_plugin/manifest.json` (раздел 3).
5. **Проверка.** Заголовок окна «Cursor MCP Plugin» (не «Talk To Figma MCP Plugin») и зелёная плашка на месте. Если подключения нет, нажми **Connect** (порт 3055). Не закрывай и не сворачивай окно. Позже подтверди успешным вызовом инструмента набора (раздел 3).
6. **Код канала.** Прочитай 8-символьный код со скриншота и перепроверь каждый символ (0 или o, l или 1). Подтверди связью: `join_channel` и `get_document_info`; при таймауте сделай новый скриншот и повтори.
7. Продолжай по разделу 5. Отчёты о ходе работы короткие: пользователь может читать с телефона. В конце экспортируй ключевые экраны и сообщи имена файла и фрейма.

## 9. Безопасность

Мост слушает `localhost:3055` без аутентификации: любая локальная программа может отправлять команды в открытый файл Figma. Никогда не открывай порт наружу и не запускай мост с `--server` на чужой хост. Один агент на канал: параллельные правки одного файла конфликтуют.

Выполнение произвольного JavaScript внутри Figma **намеренно не реализовано**: оно превратило бы локальный порт без пароля в канал запуска кода. Если задача дизайна не покрыта, предложи новую типизированную команду вместо кода.
